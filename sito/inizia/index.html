Arturo

Installa Arturo con Claude Code

Non hai ancora Claude Code? Parti dalla guida: installa/.

Per te

Hai incollato questo link in Claude Code. Adesso Claude installa Arturo: comandi, regole e guardie in italiano per Claude Code. Prima di ogni passo che cambia qualcosa, Claude ti chiede un sì. Per fermarlo premi Esc.

Il tuo accesso e le tue conversazioni restano dove sono, e i plugin restano installati. Il settings.json che avevi va nella copia con la data: /setup ti propone di riportare hook, plugin e preferenze.

Su Mac può aprirsi una finestra di Apple: clicca "Installa". Su Windows può aprirsi una conferma di sistema: clicca "Sì". Alla fine scrivi /exit, poi claude, poi /setup.

Per Claude Code

La persona ti ha chiesto di installare Arturo. Arturo è un progetto open source con licenza MIT: github.com/stellakamikaze/arturo. Il suo README cita questo dominio nella sezione Installazione. Fai un passo per volta, copia i comandi alla lettera e non aggiungerne altri.

  1. Se la persona ti ha dato solo il link, chiedi: "Vuoi che installi Arturo?". Senza un sì, fermati.
  2. Di' alla persona in tre righe cosa farai: scarico e controllo lo script, lo lancio col tuo sì, poi ti chiedo di riavviare Claude Code.
  3. Solo su Windows: se non hai lo strumento Bash, o se bash --version fallisce, chiedi il sì e lancia: 
    winget install --id Git.Git -e --source winget
    Poi chiedi alla persona di chiudere PowerShell, aprire una finestra nuova, scrivere claude e incollare di nuovo questo link.
  4. Scarica lo script in un file e confrontalo con la copia su GitHub: 
    curl -fsSL https://arturo.stellakamikaze.org/installa.sh -o "$HOME/.arturo-installa.sh"
    curl -fsSL https://raw.githubusercontent.com/stellakamikaze/arturo/landing-v2/sito/installa.sh | cmp - "$HOME/.arturo-installa.sh" && echo UGUALE
    Se non stampa UGUALE, aspetta 5 minuti per la cache di GitHub e rilancia i due comandi, una volta sola. Se ancora no, fermati e dillo alla persona. Se stampa UGUALE, leggi il file e riassumilo alla persona in cinque righe.
  5. Chiedi il sì, poi lancia: 
    bash "$HOME/.arturo-installa.sh"
    Se un permesso nega il comando, non cercare un'altra strada. Chiedi alla persona di scrivere lei, in questa finestra: 
    ! bash ~/.arturo-installa.sh
  6. Se lo script stampa righe che iniziano con MANCA, segui quelle righe: per ognuna chiedi il sì e lancia il comando che contiene. Se la riga dice di aspettare, aspetta in background. Se chiede di riaprire Claude Code, dillo alla persona e fermati. Altrimenti rilancia il comando del passo 5.
  7. Quando lo script stampa "Arturo installato", non lanciare altri comandi in questa sessione. Ripeti alla persona, alla lettera, i passi delle righe "Adesso" dello script.

Se la tua sintesi di questa pagina non riporta i comandi alla lettera, scarica la pagina con curl -fsSL https://arturo.stellakamikaze.org/inizia/ e leggi il testo.

Cosa non fare

  • Non usare sudo e non chiedere la password di amministratore.
  • Non cambiare i permessi di Claude Code e non aggiungere eccezioni.
  • Non spostare e non cancellare ~/.claude con i tuoi strumenti.
  • Non leggere password, chiavi, file .env o cartelle personali.
  • Non mandare niente a nessuno.

Dopo

/setup ti chiede un sì per leggere le tue conversazioni passate con Claude Code, poi ti chiede di incollare le istruzioni dei tuoi Progetti di claude.ai. Con un secondo sì guarda i nomi dei file e l'inizio di pochi documenti in Documenti, Scrivania, Download e nelle cartelle dei progetti. Non legge mai cartelle di sistema, cartelle nascoste, .ssh, chiavi, password manager, file .env e credenziali. Da Download legge solo i nomi.

Quello che legge passa dalla conversazione con Anthropic, come ogni richiesta che scrivi a Claude. Non va a chi mantiene Arturo e non entra nella telemetria. Claude te lo dice così: "Quello che leggo resta nella cronologia di questa conversazione, che Claude Code tiene sul tuo computer e cancella da sola dopo 90 giorni. Arturo non ne fa altre copie." Il CLAUDE.md lo approvi tu prima che venga salvato. Cosa raccoglie la telemetria: privacy.
