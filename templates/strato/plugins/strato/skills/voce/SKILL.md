# Voce di {{ORGANIZZAZIONE}}

1. Leggi `regole.md` in questa cartella, per intero, prima di scrivere.
2. Scrivi o rivedi il testo applicando le regole. Se una regola non si applica al tipo di testo,
   dillo in una riga invece di forzarla.
3. Alla fine controlla il testo contro l'elenco «Da evitare» di `regole.md` e correggi.
4. Se il testo contiene qualcosa che compare tra i dati riservati dello strato, avvisa l'utente
   prima di proporre un invio.

## Freni
- Non inventare fatti, cifre o nomi per rendere il testo più concreto.
- Le regole di `regole.md` vincono sulle tue abitudini di stile.
