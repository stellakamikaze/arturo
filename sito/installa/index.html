Installa Arturo

Cinque passi, dal computer vuoto al primo lavoro. Installi Claude Code, incolli un link, e Claude fa il resto chiedendoti conferma. Apri un passo, fai quello che dice e premi "Fatto, avanti": il passo dopo si apre da solo. Questa pagina non tocca il tuo computer.

  • Un Mac o un PC Windows, con il permesso di installare programmi.
  • Un abbonamento ad Anthropic che includa Claude Code: Pro, Max, Team, Enterprise o Console. Il piano gratuito di claude.ai non lo include.
  • Una connessione a internet. Prima di cominciare, leggi i limiti.
Il tuo computer

Riconosciuto dal browser. Cambialo se non è giusto.

    I cinque passi

    1. 1

      Claude Code è l'assistente di Anthropic che lavora sui file del tuo computer, e Arturo si appoggia sopra. Serve un piano Pro, Max, Team, Enterprise o Console: il piano gratuito di claude.ai non include Claude Code. Il terminale lo apri solo qui: dal passo 2 parli con Claude.

      1. Premi Cmd + Spazio, scrivi Terminale e premi Invio.
      2. Si apre una finestra con una riga che finisce con %. Lì incolli i comandi con Cmd + V e li fai partire con Invio.
      1. Premi il tasto Windows, scrivi PowerShell e premi Invio.
      2. Si apre una finestra con una riga che finisce con >. Lì incolli i comandi con il tasto destro del mouse e li fai partire con Invio.

      Non hai mai aperto un terminale? La guida al terminale di Anthropic lo spiega con le immagini.

      L'installazione scarica circa 270 MB e per qualche minuto non scrive niente. Non interromperla: aspetta che il terminale torni pronto per un altro comando.

      TerminaleL'installazione in PowerShell

      curl -fsSL https://claude.ai/install.sh | bash
      irm https://claude.ai/install.ps1 | iex

      TerminalePoi apri Claude Code nella stessa finestra

      claude

      Cosa vedrai

      La prima volta si apre il browser per entrare nel tuo account Anthropic. Poi Claude Code chiede se ti fidi della cartella: rispondi di sì. Compare la casella dove scrivere le richieste.

      Se non torna

      • command not found: chiudi il terminale e aprine uno nuovo, poi scrivi di nuovo claude.
      • L'installazione aveva scritto ~/.local/bin is not in your PATH: apri Claude Code con ~/.local/bin/claude. Arturo sistema il PATH quando lo installi.
      • L'accesso rifiuta il piano gratuito: Claude Code chiede un piano a pagamento.
      • Un altro errore: segui la guida di installazione di Anthropic, che ha anche le altre vie.
    2. 2

      Da qui lavori dentro Claude Code. Incolla la frase: Claude legge la pagina del link, che gli dice i passi, e ti chiede un sì prima di ogni cosa che cambia il computer. Per fermarlo premi Esc.

      Claude CodeIncolla la frase e premi Invio

      Installa Arturo: https://arturo.stellakamikaze.org/inizia/

      Cosa vedrai

      • Claude Code chiede il permesso di leggere il sito arturo.stellakamikaze.org: approva.
      • Claude ti dice in tre righe cosa farà e chiede se procedere.
      • Scarica lo script di Arturo, lo confronta con la copia su GitHub e te lo riassume. Poi chiede il permesso di lanciarlo: approva.
      • Se manca un programma, Claude lo installa col tuo sì. Su Mac si apre una finestra di Apple: clicca "Installa". Su Windows si apre una conferma di sistema: clicca "Sì".
      • Alla fine lo script scrive "Arturo installato", e Claude ti dà i comandi del passo 3.

      Il tuo accesso e le tue conversazioni restano dove sono, e i plugin restano installati. Il tuo vecchio settings.json finisce in una copia di sicurezza con la data nel nome: /setup ti propone di riportare hook, plugin e preferenze. Anche gli altri file che Arturo sostituisce vanno in quella copia.

      Se non torna

      • Il permesso per lo script viene negato: Claude ti dà una riga che comincia con !. Scrivila tu in Claude Code e premi Invio: ! bash ~/.arturo-installa.sh
      • Claude ti dice che manca Git: lo installa col tuo sì. Poi chiudi Claude Code e la sua finestra di PowerShell, apri una finestra nuova, scrivi claude e incolla di nuovo la frase.
      • Claude ti dice che manca Python: lo installa col tuo sì. Poi chiudi Claude Code e la sua finestra di PowerShell, apri una finestra nuova, scrivi claude e incolla di nuovo la frase. Al giro dopo lo script crea da solo il comando python3, che Python per Windows non ha.
      • Claude scrive che lo script non è uguale alla copia su GitHub: fermati e dimmelo.
      • Lo script scrive che ~/.claude è già un repository git che non è Arturo: usa la strada a mano, col blocco che comincia con B= dentro "Preferisco leggere i comandi". Mette da parte tutta la cartella, git compreso, in una copia con la data.
      • Lo script scrive CLAUDE_CONFIG_DIR: Arturo vive solo in ~/.claude, e con quella variabile non si installa, nemmeno a mano. Togli la variabile dal file della tua shell, apri un terminale nuovo e incolla di nuovo la frase.
      • Arturo è già installato: lo script lo dice e si ferma. Per aggiornarlo scrivi /aggiorna.

      Arturo entra in funzione in una sessione nuova di Claude Code. Nella stessa finestra scrivi tre cose, una per volta, ognuna seguita da Invio.

      Cosa vedrai

      Claude risponde in italiano e comincia /setup. Se dimentichi /setup, Arturo te lo propone alla prima risposta.

      Se non torna

      • claude risponde command not found: chiudi il terminale, aprine uno nuovo e scrivi di nuovo claude.
      • Claude non conosce /setup: Arturo non si è installato. Torna al passo 2 e leggi cosa ha scritto lo script.
    4. 4

      /setup controlla in silenzio programmi e impostazioni, e installa col tuo sì quello che manca. Poi ti fa poche domande, e a ognuna puoi dire di no.

      1. Telemetria e aggiornamenti. Claude ti dice cosa parte verso chi mantiene Arturo e come si aggiorna. Rispondi sì, oppure spegnili.
      2. Le tue conversazioni. Claude chiede un sì per leggere le tue ultime conversazioni con Claude Code. Poi ti invita a incollare le istruzioni dei tuoi Progetti di claude.ai, oppure a saltare.
      3. Le tue cartelle. Claude mostra l'elenco esatto delle cartelle che vuole guardare e cosa non legge mai. Rispondi "sì", "sì ma senza" una cartella, oppure "no". Su Mac il sistema chiede il permesso per ogni cartella: puoi dire no.
      4. La bozza. In un solo messaggio Claude mostra il tuo CLAUDE.md, con la fonte di ogni riga, e gli extra che ti propone. Correggi con parole tue, oppure scrivi "ok" e i numeri degli extra che vuoi.

      Non legge mai cartelle di sistema, cartelle nascoste, .ssh, chiavi, password manager, file .env e credenziali. Da Download legge solo i nomi. Quello che legge passa dalla conversazione con Anthropic, come ogni richiesta che scrivi a Claude: non va a chi mantiene Arturo e non entra nella telemetria. Sul computer resta solo il CLAUDE.md che approvi.

      Arturo manda dati d'uso a chi lo mantiene

      Dalla prima sessione partono pochi eventi da un elenco chiuso: quali comandi di Arturo usi, quali guardie ti fermano, come va un aggiornamento. Con loro partono un id casuale, la versione e il giorno. Mai le tue richieste, i tuoi file o dei nomi. Servono a correggere i punti dove le persone si bloccano.

      Terminale/setup te lo chiede subito. Puoi spegnerli anche dopo, in un terminale

      python3 ~/.claude/bin/arturo telemetria spegni

      Puoi spegnerli anche più tardi, e vedere cosa parte con telemetria mostra al posto di telemetria spegni. L'elenco completo è in I limiti, nella pagina principale.

      Cosa vedrai

      Claude salva il tuo CLAUDE.md dopo il tuo "ok", poi fa la verifica finale da solo.

      Se non torna

      • La bozza non ti somiglia: diglielo con parole tue, per esempio "più corto" o "togli la regola sui brief". Il file si cambia quando vuoi.
      • La verifica ha una riga FAIL: scrivi a Claude "sistemalo con me".
      • Hai chiuso a metà: scrivi di nuovo /setup, e Claude ti propone di ripartire dalla fase dove eri.
    5. 5

      Con quello che ha visto, Claude ti propone tre lavori da dieci minuti sul tuo materiale vero. Scegline uno e guardalo mentre lo fa.

      Claude CodeHai saltato le letture? Incolla questo

      Facciamo lo sparring: tre domande sul mio lavoro e un piccolo esperimento.
      • /inizio nomeRiprende un progetto da dove l'hai lasciato. Se non esiste, Claude ti chiede se crearlo: anche un libro o una ricerca.
      • /fineChiude la sessione e salva un appunto per la prossima volta.
      • ricordami di…Mette una cosa da fare nell'elenco, che ritrovi a ogni /inizio.
      • /aggiornaDi solito non serve: Arturo si aggiorna da solo quando chiudi la sessione, e la barra in basso ti dice quando c'è una versione nuova. Serve se vuoi guardare prima o tornare indietro.
      • /segnalaQualcosa di Arturo non va? Lo dici a chi lo mantiene, con una bozza scritta da Claude.

    Arturo è acceso

    Da qui la strada la fai con lui. Quando non sai da dove ripartire, scrivi /guidami. Se qualcosa non torna, /diagnosi controlla Arturo e il progetto su cui lavori.

    Com'è andata l'installazione? Dove ti sei fermato, cosa non era chiaro: dimmelo in due righe o a voce.

    A mano, da terminale

    La strada da terminale, con Claude Code chiuso. Serve se Claude Code non può lanciare lo script o se vuoi leggere ogni comando prima. Fai il passo 1, poi questi blocchi in ordine. Se ~/.claude è già un tuo repository git, il comando di "Scarica Arturo" si ferma: usa il blocco che comincia con B=. Con CLAUDE_CONFIG_DIR Arturo non si installa: togli la variabile e apri un terminale nuovo.

    1. Chiudi Claude Code. Premi Cmd + Spazio, scrivi Terminale e premi Invio.
    1. Chiudi Claude Code. Su Windows questi comandi vanno in Git Bash, che installi qui sotto con Git for Windows. In Git Bash incolli con il tasto destro del mouse e scegli Paste, oppure con Maiusc + Ins.

    1. Incolla questo comando. Si apre una finestra di Apple: scegli Installa e aspetta qualche minuto. Porta git e python3. Se il terminale risponde che sono già installati, va bene così.

    Tre righe che iniziano con OK: git, node e python3.

    Se non torna

    • Una riga dice MANCA: rifai l'installazione di quel programma, poi apri un terminale nuovo e rilancia il controllo.
    • MANCA python3, ma python --version risponde: va bene così. Python per Windows non ha il comando python3, e lo crea il comando di "Scarica Arturo".     • Su macOS il controllo può riaprire la finestra di Apple: vuol dire che git o python3 non sono ancora installati.

    Scarica Arturo

    Arturo vive nella cartella delle impostazioni di Claude Code, ~/.claude. Il comando controlla prima i programmi qui sopra e Claude Code. Poi mette Arturo dentro ~/.claude senza spostare la cartella. Il tuo accesso e le tue conversazioni restano dove sono, e i plugin restano installati. Il tuo vecchio settings.json finisce in una copia di sicurezza con la data nel nome: /setup ti propone di riportare hook, plugin e preferenze. Se Arturo è già installato, il comando si ferma: per aggiornarlo scrivi /aggiorna in Claude Code.

    Il comando scarica questo script: puoi aprirlo e leggerlo. Oppure incolla il blocco qui sotto, la strada più vecchia, senza controlli: mette da parte tutta la cartella con la data nel nome, scarica Arturo e riporta al loro posto login, sessioni, plugin e i file tuoi di un Arturo di prima. Serve anche se ~/.claude è già un tuo repository git: il git va nella copia con la cartella. Il settings.json che avevi resta nella copia: /setup ti propone di riportare hook, plugin e preferenze.

    Su Windows lancia prima, una volta, il comando qui sopra: crea il comando python3, e se ~/.claude è già un repository git si ferma da solo senza toccarlo.

    B="$HOME/.claude-backup-$(date +%Y%m%d-%H%M)"
[ -d "$HOME/.claude" ] && mv "$HOME/.claude" "$B"
git clone https://github.com/stellakamikaze/arturo.git "$HOME/.claude"
for x in .credentials.json projects history.jsonl plugins file-history jobs daemon agent-memory todos \
  CLAUDE.md settings.local.json personale hooks/hosts-interni.local hooks/bash-dispatcher.local \
  hooks/protect_claude_md.local hooks/api-fidate.local hooks/handoff-gate.local hooks/index-contenitori.local \
  hooks/inventario.local bin/fonte-task.local data/memory data/memoria data/todo \
  data/segnalazioni data/setup-fatto data/aggiornamenti.json session-env/telemetria.json \
  session-env/segnala.json session-env/novita-viste; do
  [ -e "$B/$x" ] && [ ! -e "$HOME/.claude/$x" ] && mkdir -p "$(dirname "$HOME/.claude/$x")" && mv "$B/$x" "$HOME/.claude/$x"
done

    Se non torna

    • Una riga dice MANCA per git, python3 o claude: il comando dice cosa installare e non tocca niente. Installalo, poi rilancia il comando.
    • Hai chiesto a Claude Code di lanciare questi comandi e si è fermato su Self-Modification: la sua modalità auto non lo lascia sostituire la sua cartella. Lanciali tu nel Terminale, con Claude Code chiuso.
    • MANCA node: Arturo si installa lo stesso, ma la barra in basso resta vuota finché non installi node come dice il primo blocco.
    • Hai usato il blocco esteso e leggi already exists and is not an empty directory: la prima riga non è partita. Copia di nuovo il blocco intero.
    • Hai incollato in PowerShell o nel Prompt dei comandi: lì la tilde ~ non funziona e Arturo finisce in un'altra cartella senza errori. Rifallo in Git Bash.
