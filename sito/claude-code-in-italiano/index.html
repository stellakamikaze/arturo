Cos'è Claude Code

Claude Code è l'IA di Anthropic che lavora sui file del tuo computer: legge e scrive i documenti, cerca sul web, esegue i passi che gli chiedi e riprende il lavoro dal punto in cui l'avevi lasciato.

La documentazione ufficiale lo presenta come uno strumento per chi scrive codice, perché legge un progetto, modifica i file ed esegue comandi. Le stesse capacità servono a chi lavora con le parole e con le informazioni, dato che un capitolo o una cartella di appunti sono file come gli altri. In chat incolli un testo e ricevi una risposta da copiare altrove. In Claude Code chiedi di rileggere quel capitolo o di preparare la bozza di una email, e Claude apre i file, li legge e scrive il risultato dove serve.

Claude Code gira nel terminale, la finestra dove si scrivono i comandi al computer, e Anthropic lo offre anche come app desktop, nelle estensioni per gli editor di codice e nel browser. Per usarlo serve un abbonamento a pagamento: Pro, Max, Team, Enterprise oppure la Console di Anthropic. Il piano gratuito di claude.ai non lo include.

Perché configurarlo in italiano

Claude ti risponde in italiano se gli scrivi in italiano, e la documentazione di Anthropic ha una versione italiana. Le impostazioni, gli avvisi di permesso e le istruzioni di partenza, invece, sono pensati per chi programma.

Claude Code legge da un file di impostazioni che cosa può fare senza chiederti niente, e da un file chiamato CLAUDE.md le istruzioni con cui comincia ogni sessione. Chi arriva dalla chat di solito non sa che questi file esistono, quindi non li scrive e lavora con le impostazioni di partenza, che decidono al posto suo che cosa chiedere e che cosa no.

Una configurazione in italiano fa queste scelte per te e te le spiega nella tua lingua. In Arturo l'impostazione language di Claude Code vale italian, i messaggi delle guardie che ti chiedono conferma sono scritti in italiano e i comandi hanno nomi come /inizio, /fine e /diagnosi. Quando una guardia ti ferma, quindi, leggi subito che cosa sta per succedere e che cosa perdi se confermi, senza dover decifrare un avviso tecnico.

Cosa aggiunge Arturo

Arturo è un harness per Claude Code, cioè l'insieme di regole, comandi e automazioni che gli sta attorno e ne guida il lavoro. È gratuito e open source, con licenza MIT.

Nasce dalla configurazione con cui Federico Nejrotti lavora ogni giorno in Claude Code, ripulita dai suoi dati, dalle credenziali e dai riferimenti alle sue macchine. Il README del progetto conta 23 guardie e automazioni, 11 slash command, 8 subagent e 7 skill: gli slash command sono i comandi che si scrivono con la barra davanti, i subagent sono assistenti che Claude manda a fare un compito a parte, le skill sono istruzioni che Claude carica quando gli serve un certo lavoro. Per chi non programma pesano soprattutto tre parti.

  • Le guardie: prima di un gesto che non si annulla, come cancellare una cartella, mandare un messaggio o mettere una password in un commit, Arturo ferma Claude e chiede a te. La pagina Claude Code in sicurezza le racconta una per una, con i loro messaggi.
  • Le sessioni in ordine: /inizio riprende il contesto di un progetto, i todo aperti e le scadenze, mentre /fine salva il lavoro e lascia un appunto per la volta dopo, con quello che resta da fare e chi lo deve fare. Il giorno dopo non rispieghi tutto da capo.
  • Un CLAUDE.md sul tuo lavoro: /setup controlla i programmi e poi, se gli dici sì, legge le tue conversazioni passate con Claude Code e guarda le tue cartelle di lavoro. Da lì scrive la bozza del tuo CLAUDE.md, e la salva solo dopo il tuo ok.

Accanto ci sono un curriculum di principi in italiano (docs/principi/), che spiega come lavorare con un'IA che agisce sui tuoi file, e /novita, che a ogni aggiornamento racconta che cosa è cambiato e perché.

Cosa ti serve, e cosa resta uguale

Ti servono un Mac, un PC Windows o un computer Linux, e un abbonamento Anthropic che includa Claude Code.

Gli altri programmi che usa Arturo, cioè git, Python 3.8 o successivo e node 18 o successivo, li controlla Claude e li installa col tuo sì. Su Windows Arturo lavora dentro Git Bash, la finestra dei comandi che arriva con Git: senza, Claude Code esegue i comandi con PowerShell e le guardie non li vedono.

Alcune cose Arturo non le cambia, e conviene saperle prima. Claude Code è un servizio a pagamento di un'azienda privata, che ne decide prezzi e limiti. Quello che scrivi passa dai server di Anthropic, come in chat: le guardie chiedono conferma prima che Claude legga un file segreto, ma non filtrano quello che scrivi tu. Un aggiornamento di Arturo è codice scritto da altri che gira sul tuo computer, e per questo Arturo installa da solo soltanto i rilasci firmati da chi lo mantiene. Infine Arturo manda a chi lo mantiene dati d'uso da un elenco chiuso, accesi di default: il confronto con Claude Code da solo dice che cosa esce e come si spengono.

Domande.

Claude Code parla italiano?

Sì. Claude risponde nella lingua in cui gli scrivi, e la documentazione di Anthropic ha una versione italiana. Arturo aggiunge l'impostazione della lingua, i messaggi delle guardie, i comandi e un curriculum scritti in italiano.

Serve saper programmare per usare Claude Code?

No. Con Arturo il terminale serve per installare Claude Code e per aprirlo scrivendo claude. Il resto lo chiedi a Claude a parole, e prima dei passi che non si annullano ti chiede un sì.

Arturo costa qualcosa?

Arturo è gratuito e open source, con licenza MIT. Claude Code invece richiede un abbonamento Anthropic a pagamento: Pro, Max, Team, Enterprise o Console.

Arturo esiste in inglese?

No. Uno degli impegni del progetto è che Arturo resta in italiano: comandi, messaggi e documenti sono scritti in italiano. C'è soltanto una pagina di presentazione in inglese.

Per cominciare

Installa Claude Code, aprilo e incolla questa frase. Claude legge la pagina del link, scarica Arturo e ti chiede un sì prima di ogni passo. Alla fine scrivi /exit, poi claude, poi /setup.
