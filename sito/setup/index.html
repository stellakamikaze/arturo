Installa Arturo, una tappa alla volta

Dieci tappe, dal computer vuoto alla prima sessione. Questa pagina non tocca il tuo computer: prepara i comandi, e tu li incolli dove dice il segno accanto a ogni tappa.

Il tuo computer

Riconosciuto dal browser. Cambialo se non è giusto.

Tappa 1 di 10circa venti minuti in tutto

  • Terminalei comandi del computer
  • Claude Codele richieste ad Arturo

  1. 1

    Il terminale è la finestra dove si scrivono i comandi. Ti serve per le prime sei tappe. Poi lavori dentro Claude Code.

    1. Premi Cmd + Spazio, scrivi Terminale e premi Invio.
    2. Si apre una finestra con una riga che finisce con %. Lì incolli i comandi con Cmd + V e li fai partire con Invio.
    1. Premi il tasto Windows, scrivi PowerShell e premi Invio. Ti serve per la tappa 3.
    2. Dalla tappa 4 usi Git Bash, che installi alla tappa 2. In Git Bash incolli con il tasto destro del mouse e scegli Paste, oppure con Maiusc + Ins.
    3. Ogni comando parte con Invio.

    Non hai mai aperto un terminale? La guida al terminale di Anthropic lo spiega con le immagini.

  2. 2

    Arturo usa tre programmi: git scarica Arturo e salva il tuo lavoro, python3 fa girare le guardie, node serve ad alcuni strumenti. Si installano una volta sola.

    1. Incolla questo comando. Si apre una finestra di Apple: scegli Installa e aspetta qualche minuto. Porta git e python3. Se il terminale risponde che sono già installati, va bene così.

    TerminaleIncolla e premi Invio

    xcode-select --install
    1. Scarica node da nodejs.org: la versione LTS per macOS, il file .pkg. Aprilo e segui l'installazione. Se usi già Homebrew, basta brew install node jq.
    2. Chiudi il terminale e aprine uno nuovo: vede i programmi nuovi solo da una finestra nuova.
    1. Scarica Git for Windows e installalo lasciando le opzioni come sono. Porta anche Git Bash: senza, le guardie di Arturo non vedono i comandi.
    2. Scarica Python da python.org. Nella prima finestra spunta Add python.exe to PATH, poi installa.
    3. Apri Impostazioni › App › Impostazioni app avanzate › Alias di esecuzione app e spegni i due alias di Python: rimandano al Microsoft Store e non fanno partire niente.
    4. Scarica node da nodejs.org: la versione LTS per Windows, il file .msi.
    5. Apri Git Bash dal menu Start e incolla il controllo qui sotto.

    TerminaleIl controllo in Git Bashin un terminale nuovo

    for t in git node; do command -v "$t" >/dev/null 2>&1 && echo "OK     $t" || echo "MANCA  $t"; done
python3 -c 'import sys; sys.exit(0 if sys.version_info >= (3, 8) else 1)' >/dev/null 2>&1 && echo "OK     python3" || echo "MANCA  python3"

    Cosa vedrai

    Tre righe che iniziano con OK: git, node e python3.

    Se non torna

    • Una riga dice MANCA: rifai l'installazione di quel programma, poi apri un terminale nuovo e rilancia il controllo.
    • MANCA python3 anche dopo l'installazione: spegni gli alias dello Store del passo 3.
    • Su macOS il controllo può riaprire la finestra di Apple: vuol dire che git o python3 non sono ancora installati.
  3. 3

    Claude Code è l'assistente che lavora sui file del tuo computer, e Arturo si appoggia sopra. Serve un piano Pro, Max, Team, Enterprise o Console di Anthropic: il piano gratuito di claude.ai non include Claude Code.

    TerminaleL'installazione in PowerShell, non in Git Bash

    curl -fsSL https://claude.ai/install.sh | bash
    irm https://claude.ai/install.ps1 | iex

    TerminaleIl controllo in un terminale nuovo

    claude --version

    Cosa vedrai

    Un numero di versione seguito da (Claude Code). L'accesso al tuo account arriva alla tappa 6.

    Se non torna

    • command not found: chiudi il terminale e aprine uno nuovo, poi rilancia il controllo.
    • L'errore resta: segui la guida di installazione di Anthropic, che ha anche le altre vie.
  4. 4

    Arturo vive nella cartella delle impostazioni di Claude Code, ~/.claude. Se la cartella esiste già, il primo comando la mette da parte con la data nel nome: non si perde niente.

    TerminaleIncolla le due righe insieme in Git Bash

    [ -d "$HOME/.claude" ] && mv "$HOME/.claude" "$HOME/.claude-backup-$(date +%Y%m%d-%H%M)"
git clone https://github.com/stellakamikaze/arturo.git "$HOME/.claude"

    Cosa vedrai

    Qualche riga sullo scaricamento, che arriva al 100%. Poi il terminale torna pronto per un altro comando.

    Se non torna

    • git: command not found: torna alla tappa 2.
    • already exists and is not an empty directory: la prima riga non è partita. Copia di nuovo il blocco intero.
    • Hai incollato in PowerShell o nel Prompt dei comandi: lì la tilde ~ non funziona e Arturo finisce in un'altra cartella senza errori. Rifallo in Git Bash.
  5. 5

    Quattro scelte, e la pagina prepara un blocco solo. Nome ed email servono a Git per firmare il lavoro che salvi con /fine: restano sul tuo computer, e anche un'email finta va bene.

    Arturo crea qui i tuoi progetti. Lascia vuoto per usare ~/Documents/ClaudeCode. Scrivi il percorso con la barra /.
    I messaggi delle guardie restano in italiano.

    TerminaleLe tue scelte in un blocco in Git Bash

    Scrivi nome ed email qui sopra: il blocco si compone da solo.

    Cosa vedrai

    Una riga per ogni scelta che inizia con Fatto, e alla fine Scelte salvate. Puoi rilanciare il blocco: non ripete niente.

    Se non torna

    • not a git repository o No such file: Arturo non è in ~/.claude. Torna alla tappa 4.
    • Una riga dice Non trovo: le impostazioni hanno già un valore diverso. Vai avanti: alla tappa 6 scrivi /setup e Claude sistema quella riga con te.
  6. 6

    Questo comando apre Claude Code dentro Arturo. La prima volta si apre il browser per entrare nel tuo account Anthropic.

    TerminaleIncolla e premi Invio in Git Bash

    cd ~/.claude && claude

    Cosa vedrai

    Claude Code chiede se ti fidi di questa cartella: rispondi di sì. Poi compare la casella dove scrivere le richieste.

    Se non torna

    • Il browser non si apre: copia il link che compare nel terminale e aprilo a mano.
    • L'accesso rifiuta il piano gratuito: Claude Code chiede un piano a pagamento, come dice la tappa 3.

    Da qui in poi incolli in Claude Code, non più nel terminale. Lascialo aperto.

  7. 7

    Claude impara chi sei e come vuoi lavorare da un file tuo, il CLAUDE.md. Rispondi qui, e la pagina prepara la richiesta: Claude scrive la bozza e te la mostra prima di salvarla.

    Programmi?
    Come vuoi le risposte
    Regole che consigliamoVengono dall'uso di ogni giorno. Togli quelle che non vuoi.

    Claude CodeIncolla la richiesta e premi Invio

    Scrivi qui sopra almeno il tuo nome: la richiesta si compone da sola.

    Cosa vedrai

    Claude mostra la bozza e aspetta il tuo sì. Una guardia di Arturo può chiedere il permesso di scrivere il file: è normale, approva.

    Se non torna

    La bozza non ti somiglia: diglielo con parole tue, per esempio «più corto» o «togli la regola sui brief». Il file si cambia quando vuoi.

  8. 8

    Quattro aggiunte, nessuna obbligatoria. Apri solo quelle che ti riguardano, oppure vai avanti.

    Lavoro in un'organizzazione che ha uno strato per Arturo

    Lo strato porta chi siete, la vostra voce e le regole sui dati. Lo cura un referente interno: chiedigli l'indirizzo del repository.

    Claude CodeIncolla e premi Invio

    /strato installa

    Sei tu il referente? Scrivi /strato crea in un momento a parte: è un lavoro più lungo, e la guida è in ~/.claude/docs/referente.md.

    Mi collego spesso a un mio server

    Le guardie di Arturo chiedono conferma per le connessioni verso l'esterno. Un server tuo si può segnare come fidato. Le reti di casa, come 192.168.x, lo sono già.

    Claude CodeIncolla e premi Invio

    Scrivi il nome del server qui sopra.
    Uso Arturo su più computer

    Un repository privato tuo tiene allineati i computer: /fine salva lì, /inizio riprende da lì. Serve un account GitHub. Senza, tutto funziona lo stesso e resta su questo computer.

    Claude CodeIncolla e premi Invio

    Collega Arturo a un mio repository privato su GitHub, come dice la fase 7 di /setup: Arturo resta come upstream per gli aggiornamenti. Mostrami i comandi prima di lanciarli.
    Voglio collegare Gmail, Drive e Calendar

    Il collegamento ai servizi Google ha una procedura a sé, con l'accesso al tuo account.

  9. 9

    Arturo controlla da solo che tutto sia al suo posto: impostazioni, guardie, permessi.

    Claude CodeIncolla e premi Invio

    /system-audit

    Cosa vedrai

    Un elenco di controlli e in fondo il totale, con FAIL=0. Le righe WARN sono avvisi: Claude ti dice se contano.

    Se non torna

    Una riga FAIL: scrivi a Claude «sistemalo con me». Di solito sono i permessi delle guardie, che la tappa 5 rimette a posto.

  10. 10

    Arturo adesso conosce il tuo computer, ma non ancora il tuo lavoro. Dieci minuti di sparring: tre domande su cosa fai e un piccolo esperimento.

    Claude CodeIncolla e premi Invio

    /sparring
    • /progetto nomeApre un progetto nuovo, anche un libro o una ricerca.
    • /inizio nomeRiprende un progetto da dove l'hai lasciato.
    • /fineChiude la sessione e salva un appunto per la prossima volta.
    • ricordami di…Mette una cosa da fare nell'elenco, che ritrovi a ogni /inizio.
    • /aggiornaScarica la versione nuova di Arturo dopo il tuo sì. All'avvio Arturo ti dice quando c'è.

Arturo è acceso

Da qui la strada la fai con lui. Quando non sai da dove ripartire, scrivi /guidami. Per imparare un passo alla volta, chiedigli «a che punto sono?».
