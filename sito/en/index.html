Arturo, a Claude Code harness in Italian

Arturo is a harness for knowledge work, made for people who already use AI in chat but have never opened a terminal. It is free and open source, and it speaks Italian.

What it is

Claude Code is Anthropic's AI that works on the files on your computer: it reads and writes documents, runs commands and picks up the work where you left it (official documentation). Arturo is a harness for it, the set of rules, commands and automations around Claude Code that guide its work. The README counts 23 guards and automations, 11 slash commands, 8 subagents and 7 skills. The guards stop Claude before actions that cannot be undone, such as deleting a folder, sending a message or committing a password, and ask you first.

Who it is for

I'm a writer, not a programmer, and I moved from the chat window to the terminal for two reasons. In a chat I collected the material myself: I opened the files, copied the parts I needed, pasted them into the conversation and then carried the answer back into a document. Claude Code works inside my folders, so it fetches notes, transcripts and spreadsheets on its own, compares them and writes the result to a file. The other reason is continuity: when I close a session, Arturo leaves a summary with what's left to do, and the next morning the work picks up from there instead of from a blank conversation.

Anthropic saw the same use grow across Claude Code sessions. Between October 2025 and April 2026, writing and data analysis roughly doubled, from about 10% to 20% of sessions, and people outside software reached verified success in about 26% of their sessions, against 30% for software occupations. The gap is four points, and according to the study knowing your field matters more than knowing how to code. The study concludes that what happens on Claude Code may be a preview of where knowledge work is headed. Two people who don't work for Anthropic reach a similar conclusion. Simon Willison, an independent programmer who has written about these tools for years, wrote that Claude Code is poorly named, because it is a tool for general computer automation and not only for writing code. Ethan Mollick, who studies AI at work at Wharton, points to the same reason I found: Claude Code is powerful because it works on your computer and your files, and it is useful to knowledge workers of all types, even though it is built for programmers. That is why I built Arturo, which sets Claude Code up for people who don't code.

Independent evidence also shows where AI gets things wrong. In a 2023 experiment by Harvard and Boston Consulting Group with 758 consultants, those using GPT-4 on tasks within the AI's reach finished 12.2% more of them, 25.1% faster and at 40% higher quality; on a task built to fall outside it, those using AI got the right answer 60 to 70% of the time, against 84% for those working without it. A Microsoft Research study of 319 knowledge workers found that knowledge workers with higher confidence in AI report using less critical thinking. And Willison warns that an agent that reads your private data, meets text written by others and can communicate externally can be used to steal it, because that text can carry instructions the agent follows as if they came from you.

Arturo answers these risks in two different ways. Against data theft it has rules that ask for a yes before any step that can't be undone, such as deleting a folder or sending a message; the same check for web pages that carry data out is still being built. Against a wrong answer accepted on trust no rule is enough: the person doing the work checks the result, which is why knowing your field matters, as Anthropic's study also says.

People who already use ChatGPT or Claude in chat, mostly for writing, research and keeping documents in order, and want the AI to work inside their folders without learning the terminal. Arturo speaks Italian: its commands, guard messages, setup and documentation are in Italian, and staying in Italian is one of the project's commitments. This is its only page in English.

How to install

Install Claude Code, which needs a paid Anthropic plan that includes it (Pro, Max, Team, Enterprise or Console). Open it and paste this sentence, Italian for "Install Arturo":

Installa Arturo: https://arturo.stellakamikaze.org/inizia/

Claude reads the linked page, downloads Arturo's install script, compares it with the copy on GitHub and runs it after you say yes. Then type /exit, claude and /setup. The step-by-step guide is in Italian, and the code is on GitHub.

Before you start: Claude Code is a paid service, and what you write goes through Anthropic's servers. Arturo sends usage events from a closed list to its maintainer, on by default and never your texts or files; python3 ~/.claude/bin/arturo telemetria spegni turns them off. Arturo is maintained by one person, Federico Nejrotti.

Questions.

Does Arturo work in English?

No. Its commands, guard messages and documents are in Italian, and the project has committed to staying in Italian. Claude itself answers in the language you write in.

What does it cost?

Arturo is free and MIT-licensed. Claude Code needs a paid Anthropic plan: Pro, Max, Team, Enterprise or Console.

Where is the source code?

On GitHub, at github.com/stellakamikaze/arturo, under the MIT license.
