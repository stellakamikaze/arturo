Installa Arturo

Dieci passi, dal computer vuoto al primo lavoro. Apri un passo, fai quello che dice e premi «Fatto, avanti»: il passo dopo si apre da solo. Questa pagina non tocca il tuo computer. Prepara i comandi, e tu li incolli dove dice il segno accanto a ogni passo.

  • Un Mac o un PC Windows, con il permesso di installare programmi.
  • Un abbonamento ad Anthropic che includa Claude Code: Pro, Max, Team, Enterprise o Console. Il piano gratuito di claude.ai non lo include.
  • Circa un'ora e una connessione a internet. Prima di cominciare, leggi i limiti.

Riconosciuto dal browser. Cambialo se non è giusto.

    I dieci passi

    1. 1

      Il terminale è la finestra dove si scrivono i comandi. Ti serve per i primi sei passi. Poi lavori dentro Claude Code.

      1. Premi Cmd + Spazio, scrivi Terminale e premi Invio.
      2. Si apre una finestra con una riga che finisce con %. Lì incolli i comandi con Cmd + V e li fai partire con Invio.
      1. Premi il tasto Windows, scrivi PowerShell e premi Invio. Ti serve per il passo 3.
      2. Dal passo 4 usi Git Bash, che installi al passo 2. In Git Bash incolli con il tasto destro del mouse e scegli Paste, oppure con Maiusc + Ins.
      3. Ogni comando parte con Invio.

      Non hai mai aperto un terminale? La guida al terminale di Anthropic lo spiega con le immagini.

    2. 2

      Arturo usa tre programmi: git scarica Arturo e salva il tuo lavoro, python3 fa girare le guardie, node serve ad alcuni strumenti. Si installano una volta sola.

      1. Incolla questo comando. Si apre una finestra di Apple: scegli Installa e aspetta qualche minuto. Porta git e python3. Se il terminale risponde che sono già installati, va bene così.

      TerminaleIncolla e premi Invio

      xcode-select --install
      1. Scarica node da nodejs.org: la versione LTS per macOS, il file .pkg. Aprilo e segui l'installazione. Se usi già Homebrew, basta brew install node jq.
      2. Chiudi il terminale e aprine uno nuovo: vede i programmi nuovi solo da una finestra nuova.
      1. Scarica Git for Windows e installalo lasciando le opzioni come sono. Porta anche Git Bash: senza, le guardie di Arturo non vedono i comandi.
      2. Scarica Python da python.org. Nella prima finestra spunta Add python.exe to PATH, poi installa.
      3. Apri Impostazioni › App › Impostazioni app avanzate › Alias di esecuzione app e spegni i due alias di Python: rimandano al Microsoft Store e non fanno partire niente.
      4. Scarica node da nodejs.org: la versione LTS per Windows, il file .msi.
      5. Apri Git Bash dal menu Start e incolla il controllo qui sotto.

      TerminaleIl controllo in Git Bashin un terminale nuovo

      for t in git node; do command -v "$t" >/dev/null 2>&1 && echo "OK     $t" || echo "MANCA  $t"; done
python3 -c 'import sys; sys.exit(0 if sys.version_info >= (3, 8) else 1)' >/dev/null 2>&1 && echo "OK     python3" || echo "MANCA  python3"

      Cosa vedrai

      Tre righe che iniziano con OK: git, node e python3.

      Se non torna

      • Una riga dice MANCA: rifai l'installazione di quel programma, poi apri un terminale nuovo e rilancia il controllo.
      • MANCA python3 anche dopo l'installazione: spegni gli alias dello Store del passo 3.
      • Su macOS il controllo può riaprire la finestra di Apple: vuol dire che git o python3 non sono ancora installati.
    3. 3

      Claude Code è l'assistente che lavora sui file del tuo computer, e Arturo si appoggia sopra. Serve un piano Pro, Max, Team, Enterprise o Console di Anthropic: il piano gratuito di claude.ai non include Claude Code.

      L'installazione scarica circa 270 MB e per qualche minuto non scrive niente. Non interromperla: aspetta che il terminale torni pronto per un altro comando.

      TerminaleL'installazione in PowerShell, non in Git Bash

      curl -fsSL https://claude.ai/install.sh | bash
      irm https://claude.ai/install.ps1 | iex

      TerminaleIl controllo in un terminale nuovo

      claude --version

      Cosa vedrai

      Un numero di versione seguito da (Claude Code). L'accesso al tuo account arriva al passo 6.

      Se non torna

      • command not found: chiudi il terminale e aprine uno nuovo, poi rilancia il controllo.
      • L'errore resta, e l'installazione aveva scritto ~/.local/bin is not in your PATH: vai avanti al passo 4. Il comando di Arturo sistema il PATH da solo.
      • Un altro errore: segui la guida di installazione di Anthropic, che ha anche le altre vie.
    4. 4

      Arturo vive nella cartella delle impostazioni di Claude Code, ~/.claude. Il comando controlla prima i programmi dei passi 2 e 3. Poi mette da parte la cartella che c'è già, con la data nel nome: non si perde niente. Login, sessioni e plugin tornano subito al loro posto. Se nella cartella c'erano il tuo CLAUDE.md, la memoria, i todo e le scelte di Arturo, tornano anche quelli. Se Arturo è già installato, il comando si ferma: per aggiornarlo scrivi /aggiorna in Claude Code, per reinstallarlo da capo usa i comandi qui sotto. Se un'altra app aveva aggiunto i suoi hook a Claude Code (ClaudeBar, una barra di stato), al passo 6 /setup li ritrova e, col tuo sì, li rimette.

      TerminaleIncolla e premi Invio in Git Bash

      curl -fsSL https://arturo.stellakamikaze.org/installa.sh | bash
      Preferisco leggere i comandi prima di lanciarli

      Il comando scarica questo script: puoi aprirlo e leggerlo. Oppure incolla al suo posto il blocco qui sotto, che fa lo stesso senza i controlli.

      B="$HOME/.claude-backup-$(date +%Y%m%d-%H%M)"
[ -d "$HOME/.claude" ] && mv "$HOME/.claude" "$B"
git clone https://github.com/stellakamikaze/arturo.git "$HOME/.claude"
for x in .credentials.json projects history.jsonl plugins file-history jobs daemon agent-memory todos \
  CLAUDE.md settings.local.json personale hooks/hosts-interni.local data/memory data/memoria data/todo \
  data/segnalazioni data/setup-fatto data/aggiornamenti.json session-env/telemetria.json \
  session-env/segnala.json session-env/novita-viste; do
  [ -e "$B/$x" ] && [ ! -e "$HOME/.claude/$x" ] && mkdir -p "$(dirname "$HOME/.claude/$x")" && mv "$B/$x" "$HOME/.claude/$x"
done

      Cosa vedrai

      Una riga OK per ogni programma, poi Arturo installato e i tre passi che seguono.

      Se non torna

      • Una riga dice MANCA per git, python3 o claude: il comando dice cosa installare e non tocca niente. Installalo, poi rilancia il comando.
      • Hai chiesto a Claude Code di installare Arturo e si è fermato su Self-Modification: la sua modalità auto non lo lascia sostituire la sua cartella. Lancia tu il comando nel Terminale, con Claude Code chiuso.
      • MANCA node: Arturo si installa lo stesso, ma la barra in basso resta vuota finché non installi node come al passo 2.
      • Hai usato il blocco esteso e leggi already exists and is not an empty directory: la prima riga non è partita. Copia di nuovo il blocco intero.
      • Hai incollato in PowerShell o nel Prompt dei comandi: lì la tilde ~ non funziona e Arturo finisce in un'altra cartella senza errori. Rifallo in Git Bash.

      Arturo manda dati d'uso a chi lo mantiene

      Dalla prima sessione partono pochi eventi da un elenco chiuso: quali comandi di Arturo usi, quali guardie ti fermano, come va un aggiornamento. Con loro partono un id casuale, la versione e il giorno. Mai le tue richieste, i tuoi file o dei nomi. Servono a correggere i punti dove le persone si bloccano.

      TerminaleSe non li vuoi, incolla questo prima di andare avanti in Git Bash

      python3 ~/.claude/bin/arturo telemetria spegni

      Puoi spegnerli anche più tardi, e vedere cosa parte con telemetria mostra al posto di telemetria spegni. L'elenco completo è in I limiti, nella pagina principale.

      I messaggi delle guardie restano in italiano.

      Scrivi nome ed email qui sopra: il blocco si compone da solo.

      Cosa vedrai

      Se non torna

      • not a git repository o No such file: Arturo non è in ~/.claude. Torna al passo 4.
      • Una riga dice Non trovo: le impostazioni hanno già un valore diverso. Vai avanti: al passo 6 scrivi /setup e Claude sistema quella riga con te.
    6. 6

      Questo comando apre Claude Code dentro Arturo. La prima volta si apre il browser per entrare nel tuo account Anthropic.

      Cosa vedrai

      Claude Code chiede se ti fidi di questa cartella: rispondi di sì. Poi compare la casella dove scrivere le richieste.

      Se non torna

      • Il browser non si apre: copia il link che compare nel terminale e aprilo a mano.
      • L'accesso rifiuta il piano gratuito: Claude Code chiede un piano a pagamento, come dice il passo 3.

      Da qui in poi incolli in Claude Code, non più nel terminale. Lascialo aperto.

      Arturo controlla da solo che tutto sia al suo posto: impostazioni, guardie, permessi.

    10. 10

      Arturo adesso conosce il tuo computer, ma non ancora il tuo lavoro. Dieci minuti di sparring: tre domande su cosa fai e un piccolo esperimento.

      Claude CodeIncolla e premi Invio

      Facciamo lo sparring: tre domande sul mio lavoro e un piccolo esperimento.
      • /inizio nomeRiprende un progetto da dove l'hai lasciato. Se non esiste, Claude ti chiede se crearlo: anche un libro o una ricerca.
      • /fineChiude la sessione e salva un appunto per la prossima volta.
      • ricordami di…Mette una cosa da fare nell'elenco, che ritrovi a ogni /inizio.
      • /aggiornaDi solito non serve: Arturo si aggiorna da solo quando chiudi la sessione, e la barra in basso ti dice quando c'è una versione nuova. Serve se vuoi guardare prima o tornare indietro.
      • /segnalaQualcosa di Arturo non va? Lo dici a chi lo mantiene, con una bozza scritta da Claude.

    Arturo è acceso

    Da qui la strada la fai con lui. Quando non sai da dove ripartire, scrivi /guidami. Se qualcosa non torna, /diagnosi controlla Arturo e il progetto su cui lavori.

    Com'è andata l'installazione? Dove ti sei fermato, cosa non era chiaro: dimmelo in due righe o a voce.
